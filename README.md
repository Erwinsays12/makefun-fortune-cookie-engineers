## What it does

`main.ts` writes a single one-line fortune cookie message for a software
engineer (120 characters or fewer) to `/output/entry.txt`. The line was
chosen as the champion of a 12-candidate internal tournament judged against
the competition rubric: a real fortune-cookie message for an engineer, a
joke that lands on the first read, short and declarative, fresh, and tight
with the funniest word at the end.

> Your pull request will be approved in minutes. The reviewer did not read it. Neither did you.

## Run

```sh
node main.ts
```

It writes `/output/entry.txt` (93 characters, one line).
